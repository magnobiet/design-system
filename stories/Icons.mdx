# Ícones

Duas bibliotecas, cada uma com um papel claro: [Lucide](https://lucide.dev/) para interface e [Simple Icons](https://simpleicons.org/) para marcas de terceiros. Não misturar as duas no mesmo componente.

Os exemplos abaixo usam SVGs importados com `?raw` via Vite. No código da aplicação, prefira o pacote do framework (`lucide-react`, `lucide-angular`, etc.).

## Interface (Lucide)

Geométricos, outline, stroke uniforme: `1.5px` para detalhes, `2px` padrão e `2.5px` para destaque. Tamanho padrão de `24px` com área de toque mínima de `44px`.

## Convenções

<Markdown>
{`
| Regra | Orientação |
| ----- | ---------- |
| Interface | [Lucide](https://lucide.dev/) para ícones de UI |
| Marcas | [Simple Icons](https://simpleicons.org/) para logos de terceiros |
| Tamanho | \`24px\` padrão; área de toque mínima de \`44px\` |
| Cor (marcas) | Usar a cor oficial ou \`#F4F7FF\` sobre fundos escuros |
| Separação | Não misturar Lucide e Simple Icons no mesmo componente |
| Distorção | Não distorcer, recolorir fora do padrão ou modificar a geometria |
`}
</Markdown>

O catálogo completo do Simple Icons está em [simpleicons.org](https://simpleicons.org/). O slug de cada ícone está no [repositório oficial](https://github.com/simple-icons/simple-icons/blob/develop/slugs.md).
