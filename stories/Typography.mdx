# Tipografia

Três famílias, cada uma com um papel claro. Não misturar outras além dessas.

- **Space Grotesk**: títulos e display (H1 a H4, headlines, números de destaque). Peso 600, tracking apertado.
- **Inter**: corpo e controles (parágrafos, navegação, botões, formulários, labels).
- **JetBrains Mono**: dados e código (blocos de código, métricas, parâmetros, labels técnicos). Usar figuras tabulares para evitar deslocamento de layout.
