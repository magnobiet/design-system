# Cores

Paleta calibrada para contraste sobre base azul-marinho profunda. Distribuição recomendada: `60%` fundo e superfícies escuras, `20%` superfícies elevadas, `10%` marca e `10%` divididos entre accent, terciária, tipografia e elementos claros.

## Superfícies

Superfícies escuras em camadas. Cada uma delimitada por borda estrutural `1px solid #27314D`.

## Estados funcionais

Cores funcionais complementam a identidade, nunca substituem. Não use cor como único recurso para comunicar estado.
